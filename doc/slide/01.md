# 01
## technical details for automated video baking
### технические детали для автоматизированной генерации видео

- slide content: **Markdown**
    - syntax coloring (Python, FORTH, C++)
    - diagrams: **mermaid**
- automation sсripts: **Python**
- voice synthesis: **[Voicegenerator](https://voicegenerator.io/)**
- YouTube video config:
    - cheap/old mobile phone: 1280 x 720 landscape 5"
    - container: MP4
    - video: H.264 HD/720p high 4:2:0 15fps Rec.709
    - audio: AAC-LC 44.100kHz 128kbps (mono)

## subtitles
### ru

Этот курс был создан с использованием инструментов для автоматической генерации
видео- и аудиоконтента. Содержимое каждого слайда задаётся в виде текстовых
описаний в форматах типа Markdown, mermaid, и фрагментах исходного кода. Процесс
сборки видео автоматизирован с помощью Python-скриптов. Это позволяет быстро
обновлять контент, вносить правки и генерировать новые версии уроков.

Озвучка курса создана с использованием синтеза речи. Это позволяет получить
аудиосопровождение материала, хорошо воспринимаемое на слух, без шумов, фефектов
фикции, дикторских косяков, проблем с микрофонами и ручной пост-обработкой
аудио.

Кроме того, голосовой синтез позволяет легко корректировать текст, переводить
его на любой язык, и включать текстовые субтитры.

Готовые видео публикуются на YouTube и других видеоплатформах, для каждой из
которых можно настроить оптимальные размеры, параметры видео- и аудиокодеков, и
собрать варианты в разном разрешении для просмотра на телефоне, или на большом
экране.
