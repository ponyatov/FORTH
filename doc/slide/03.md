## Markdown render
### рендер слайдов Markdown

## subtitles
### ru

Для подготовки слайдов вполне подходит разметка Markdown с некоторыми
расширениями, включающими подсветку синтаксиса, и отображение векторных
элементов (диаграммы и иллюстрации).

Использование вектора позволяет менять размер кадра в широких пределах, например
менять ориентацию между горизонтальным полноразмерным видео, и вертикальными
shorts, при этом иллюстрации будут оставаться качественными и без растровых
артефактов.
