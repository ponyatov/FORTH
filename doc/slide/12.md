### 12: Short FORTH intro

![](https://www.forth.com/wp-content/uploads/2015/03/ch1-washer.gif)

```
: FILL          FAUCETS OPEN  TILL-FULL           FAUCETS CLOSE ;
: ЗАЛИТЬ        КРАН ОТКРЫТЬ  ОЖИДАТЬ-ЗАПОЛНЕНИЯ  КРАН ЗАКРЫТЬ  ;
```

- `OPEN`/`CLOSE` generic **action**
- `FAUCETS` is **argument** for following word, points hardware component
- `DOOR OPEN` uses the same `OPEN` word, but opens machine door latch

```
pin17 const FAUCETS \ КРАН
pin34 const DOOR    \ ДВЕРКА
```

## subtitles
### ru

В этом определении мы сначала ссылаемся на один из компонентов стиральной
машины, а затем применяем к нему общие операцию -- открыть и закрыть. Поскольку
в стиральной машине есть как минимум водяной клапан и дверца, для слов `ОТКРЫТЬ`
и `ЗАКРЫТЬ` нужно передать параметр -- что именно.

Производитель стиральной машины уже прописал набор констант, указывающих каким
выводом микроконтроллера управляется каждый элемент машины. Слова `ОТКРЫТЬ` и
`ЗАКРЫТЬ` только выводят единицу или ноль на ранее выбранный GPIO-пин.
