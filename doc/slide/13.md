### 13: Short FORTH intro

![](https://www.forth.com/wp-content/uploads/2015/03/ch1-washer.gif)

```
: FILL          FAUCETS OPEN  TILL-FULL           FAUCETS CLOSE ;
: ЗАЛИТЬ        КРАН ОТКРЫТЬ  ОЖИДАТЬ-ЗАПОЛНЕНИЯ  КРАН ЗАКРЫТЬ  ;
```

- `TILL-FULL` was earlier defined as awaiting loop:
  - continuously checks water level sensor to end a loop
  - counts number of loop passes to limit the filling time
  - if counter overflows the error state must be raised as something goes wrong
  - runs some short `DELAY` to limit sensor reading rate, and do something else
    in parallel threads (read user control panel, check water temperature, etc)

## subtitles
### ru

Слово `ОЖИДАТЬ-ЗАПОЛНЕНИЯ` было определено как цикл ожидания. Оно постоянно
проверяет состояние датчика уровня воды, чтобы завершить цикл.

Также на каждом проходе цикла увеличивается счётчик цикла, чтобы ограничить
максимальное время наполнения бака. Если этот счётчик переполняется, значит
что-то идёт не так, и нужно выставить состояние ошибки и переключиться в
аварийный режим.

Ещё нужно выполнить слово `ПАУЗА` с короткой задержкой, чтобы не только не
опрашивать датчик уровня воды слишком часто, но и успеть что-то сделать в
параллельных потоках программы (обработать нажатия кнопок на панели управления,
проверить температуру воды, и т.п.)
