### 16: Interactive REPL

![](https://nncron.ru/help/EN/images/console.png)

- every FORTH console has some text input field or command line editor
- run command by pressing [Enter] or [Return] (on retro computers)
- program outputs into scrollable log-like window or text screen
- optional: some systems show current data stack dump

## subtitles
### ru

Каждая форт-консоль имеет поле ввода, или строковый редактор для ввода
форт-команд.

Введеная команда запускается на выполнение нажатием на Enter (или Return на
ретро-компьютерах).

Программа или команды выводят результаты в скроллируемое окно, или на текстовый
экран в полноэкранном режиме.

Некоторые форт-системы после ввода каждой команды отображают содержимое стека
данных, на котором хранятся промежуточные данные и параметры команд.
