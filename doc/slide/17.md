### 17: Interactive REPL

- enter this into REPL command editor, but don't press [Enter]:
```
15 SPACES
```
- you can delete last chars by [Backspace]
- some editors allows to move with [<-] [->] and [Del]ete some internal text
- [Ctrl] + arrows moves cursor by words
- [Enter] runs entered command
- `ok` or other text marker shows command execution end

```
15 SPACES↵                 ok
> _
```

## subtitles
### ru

Введине команду `15 SPACES` в строку редактора команд, но не нажимайте [Enter].
Вы можете удалять последние введённые символы кнопкой [Backspace]. Большинство
редакторов позволяют перемещаться внутри команды курсорными клавишами
посимвольно, а с зажатым [Control] по словам.

После нажатия [Enter] команда выполняется, затем выводится текст `ok`, или
просто появляется приглашение для ввода следующей команды. Некоторые системы
выводят после выполнения команды содержимое стека.
