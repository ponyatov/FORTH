### 18: Interactive REPL

```
42 EMIT
```
- `*` symbol should be printed
- integer numbers will be used as is:
  - numbers will be pushed on **data stack** (see next)
  - `42` puts ASCII code of `*`
- words will be searched in FORTH **vocabulary** (of known words)
  - found word will be executed
  - or *NOT FOUND* error message will break command execution
  - `EMIT` takes ASCII code from stack, and output corresponding symbol
- if you enter number and word in separate commands, you can see intermediate
  data passes in stack dumps

## subtitles
### ru

Команда `42 EMIT` выведет звёздочку.

Несколько слов, введённых через пробелы, исполняются последовательно слева
направо.

Числа кладутся на стэк данных (который будет подробно рассмотрен далее).

Слова ищутся в словаре форт-системы, и выполняются. Если слово неизвестно,
выводится сообщение об ошибке.

Если ваша форт-система выводит стэк данных в конце выполнения команд, вы можете
ввести отдельно число, и отдельно слово, чтобы увидеть передачу данных. Если
сначала ввести числа 42 43 44, а потом сделать `EMIT` по одному, вы увидите как
работает стэк: слово с одним параметром берёт только последний элемент.
