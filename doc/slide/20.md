### 20: Counted Loop
#### цикл со счётчиком

```
: BAR ( n -- )
    ( n ) 0 DO
        STAR \ prints single *
    LOOP
;
```
- any text in `( )` is **block comment**
  - `( -- )` is **stack effect notation**: stack state before and after word run
- `\` is **line comment**: all text will be ignored until end of line
- `DO` starts loop compilation, and marks current code position in **return stack**
- `LOOP` ends loop by compiling reverse and forward jumps at marked loop start

## subtitles
### ru

Чтобы определить слово, выводящее линейку из нескольких звёздочек, нам нужен
цикл со счётчиком. Этот цикл умеют компилировать IMMEDIATE-слова `DO` и `LOOP`.

Слово `DO` запоминает адрес начала цикла, и компилирует код проверки и
инкремента счётчика цикла. В этом коде есть машинная команда условного перехода
вперёд если счётчик дошёл до конца, но поскольку мы ещё не знаем где
заканчивается цикл, в этой команде компилируется фиктивный адрес.

Слово `LOOP` может получить запомненный адрес начала цикла со стека возвратов,
поэтому оно не только компилирует команду безусловного перехода на начало цикла,
но и модифицирует уже скомпилированную команду перехода в начале, исправляя в
ней адрес перехода вперёд. Такая техника однопроходной компиляции называется
backpatching.
