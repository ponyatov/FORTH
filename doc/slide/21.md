### 21: Counted Loop
#### цикл со счётчиком

```
( start end ) DO .. LOOP
```
- `DO` takes two parameters from data stack:
  - `start` initial value of the **loop counter** (often called the **index**)
  - `end` loop runs until the index reaches this value. *It is exclusive*.
- `LOOP` marks the end of counted loop
  - if loop counter reaches `end` value, loop stops by jumping out at next
    command after a `LOOP`
- `I` word in loop body pushes current loop counter onto data stack
  - `J` and `K` pushes counters for outer loops

## subtitles
### ru

Если рассматривать DO-LOOP как синтаксическую конструкцию, без деталей её
компиляции, синтаксис показан на слайде. Однако всё же не забываем, что Форт это
no-syntax язык с однопроходной компиляцией -- в Форте всё есть слово, а если вам
нужно добавить какой-то свой синтаксис, форт-система предоставляет вам прямой
доступ к внутренностям компилятора, причем в рантайме.

Перед словом `DO` на стеке должно лежать два значения: начальное и конечное
значения счётчика цикла. Часто конечное значение указывается нулём, а начальное
положительное -- тогда цикл выполняется указанное количество раз.

Отдельно следует упомянуть, что в отличие от других языков, в Форте индекс
уменьшается а не увеличивается. Это связано не только с особенностями машинных
команд цикла, которые есть на некоторых платформах, но скорее это вынужденная
мера позволяющая опускать стартовое значение индекса при компиляции цикла
DO-LOOP внутрь других слов.
