### 26: Concatenative Programming
#### конкатенативное программирование

- **shared global stack** allows to easily integrate tiny code/words into a larger
  ones
- simple and light translators
- disadvantages:
  - complex code read & debug (stack tracking needed)
  - сhallenges with сomplex expressions require infix -> postfix translation

```Rust
pub static arg:Stack;
fn X(arg:Stack) -> arg:Stack
fn Y(arg:Stack) -> arg:Stack

// X Y Z
arg = Z(Y(X(arg)));
```

## subtitles
### ru

конкатенативное программирование — это парадигма программирования, в которой
программы строятся путём композиции (соединения) функций, где каждая функция
принимает и возвращает один и тот же тип данных (обычно стэк).

В конкатенативных языках:
- программа это множество независимых функций (форт-слов)
- выполнение программы это применение функций в порядке их записи
- нет явных аргументов — данные хранятся и передаются через глобальную
  разделяемую структуру данных

Принцип математической композиции двух и более функций противопоставляется
аппликативному стилю, где функциям явно передаются аргументы. Для реализации
этого подхода функции обычно проектируются как унарные: они принимают один
аргумент (состояние стэка) и возвращают одно значение (новое состояние стэка).
Это позволяет отказаться от явного указания аргументов и использовать
бесточечный стиль (point-free) программирования.
