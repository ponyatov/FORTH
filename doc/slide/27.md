### 27: It's Time To Start!
#### продолжаем продолжать

Common ideas of FORTH looks familiar, so it's time to start with our own!

concepts:

- high-level *FORTH Virtual Machine* model
- high-level language to make it fast and easy for anybody
- move a bit from standard FORTH as we have no direct memory and low-level
  operations
- use modern IDE for debug and tracking, and Python REPL for entry-stage
  interaction
- target students and low-qualified developers

### ru

Теперь общие идеи базового Форта кажутся вам знакомыми, так что пришло время
начать нашу собственную реализацию.

Перечислим некоторые концепции, которых мы будет придерживаться:

- мы реализуем максимально высокоуровневую модель *виртуальной Форт-машины*
- используем высокоуровневый язык программирования, обеспечивающий быстроту и
  простоту разработки
- немного отходим от стандартного Форта, поскольку у нас нет прямого доступа к
памяти, и недоступны низкоуровневые операции: работаем в пределах виртуальной
машины языка Python
- используем современную IDE для отладки и отслеживания, а также Python REPL для
начального взаимодействия с системой
- ориентируемся на студентов и разработчиков с низкой квалификацией
