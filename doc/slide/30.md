***30: Stack Operations***

```py
## `( -- cell )` push any Python object into @ref D data stack
def push(cell): D.append(cell); return D
## `( cell -- )` pop top element
def pop(): return D.pop()
## `( cell -- cell )` get top element w/o removing
def top(): return D[-1]

class TestD:
    @pytest.fixture(autouse=True)
    def clear_stack(self): global D; D.clear()
    def test_push(self): assert push(1) == [1]; assert D == [1]
    def test_pop(self): push(1); assert pop() == 1; assert D == []
    def test_top(self): push(1); assert top() == 1; assert D == [1]
```

## subtitles
### ru

Для любого стека есть три базовых операции:
- пуш: вталкивает объект на вершину стека
- поп: выталкивает объект с вершины, удаляя его из стека
- топ: возвращает объект на вершине (без удаления)

`cell` это тип данных в Форте, который соответствует любому типу, который может
уместится в одном элементе стека.

В низкоуровневых реализациях `cell` соответствует адресу памяти форт-системы, то
есть это машинное слово, или шестнадцатибитный адрес для восьмибитных платформ.
Одновременно cell представляет любые примитивные типы: байты, отдельные
текстовые символы, целые числа со знаком, беззнаковые целые, и иногда числа с
плавающей точкой. Другие типы, такие как строки, в низкоуровневом Форте
представляются на стеке в виде адреса памяти (указателя), редко индекса в
некоторой системной таблице.

При реализации Форта на высокоуровневом языке `cell` соответствует одновременно
как примитивным и value-типам, так и ссылочным типам (то есть скрытый
указатель или слайс).

В нашем случае Python скрывает такие детали, поэтому считайте cell синонимом
типа object.
