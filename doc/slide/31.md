***31: Stack Operations***

```py
## `( ... -- ... n )` get stack depth: number of elements
def depth(): push(len(D)); return D
## `( ... -- )` clean the whole @ref D data stack
def clear(): D.clear(); return D

class TestD:
    @pytest.fixture(autouse=True)
    def clear_stack(self): clear()
    def test_clear(self): clear(); depth(); assert D == [0]
    def test_depth(self):
        assert depth() == [0]
        push(1); push(2); push(3)
        assert depth() == [0, 1, 2, 3, 4] # previous and new depth's
```

## subtitles
### ru

- `DEPTH`: положить размер стека (до выполнения команды) на его вершину
- `CLEAR`: полная очистка стека
