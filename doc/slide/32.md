***32: Stack Operations***

```py
## `DUP ( a -- a a )` duplicate top element
def dup(): push(top())

## `DROP ( a b -- a )` drop top element
def drop(): pop()

## `PRESS ( a b -- b )` drop sub-top element
def press(): pop(1)

## `SWAP ( a b -- b a )` swap two elements
def swap(): a = pop(); b = pop(); push(a); push(b)

## `OVER ( a b -- a b a )` copy sub-top element
def over(): push(top())
```

## subtitles
### ru

Для эффективной работы со стэком данных в Форте существует набор фундаментальных
операций перестановки и копирования элементов. Эти слова постоянно используются
при написании форт-программ для склейки слов, и в определённом смысле являются
одним из недостатков языка - синтаксическим шумом в коде.

- `DUP` дублирует верхний элемент стэка. Это полезно когда нужно использовать
значение несколько раз без повторного вычисления.

- `DROP` удаляет верхний элемент, очищая стэк от ненужных промежуточных
  результатов.

- `SWAP` меняет местами два верхних элемента. Критически важно когда порядок
аргументов не совпадает с ожиданиями следующей операции.

- `OVER` копирует второй элемент сверху на вершину стэка. Позволяет "заглянуть"
глубже в стэк без нарушения его структуры.

Эти операции образуют базовый "алфавит" для манипуляций со стэком в
конкатенативном программировании. Их комбинации позволяют реорганизовывать
данные на стеке для любой требуемой последовательности операций.
