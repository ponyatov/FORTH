***33: Stack Operations***

```py
## `ROT ( a b c -- b c a )` rotate cw
def rot(): push(pop(2))

## `-ROT ( a b c -- c a b )` rotate ccw
def mrot(): D.insert(-2, pop())

## `PICK ( ... n -- ... D[n] )` pick n-th stack item counting from stack top down
def pick(): push(D[-1 - pop()])

## `( cell -- )` pop top element
## @param[in] idx optional stack index counting from stack top down
def pop(idx=0): return D.pop(-1 - idx)
```

## subtitles
### ru

операции `рот` и `мрот` позволяют манипулировать тремя верхними элементами
стека, переворачивая внутренний элемент на вершину, либо перемещая вершину
внутрь.
- `рот` циклически сдвигает три верхних элемента стека по часовой стрелке
- `мрот` делает циклический сдвиг против часовой стрелки

операция `пик` позволяет вытащить на вершину стека произвольный внутренний
элемент, индексируя его от вершины вглубь: вершина стека имеен индекс ноль,
элемент под вершиной один, и так далее. Элементы не удаляются, а индекс на
вершине замещается выбранным элементом.

для реализации адресации стека функция `поп` была расширена параметром для
адресации стека с нулевым значением по умолчанию (для вершины)
