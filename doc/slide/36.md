***36: System Control***

```py
import sys, time

## `NOP ( -- )` do nothing command
def nop(): pass

## `BYE ( -- )` terminate system (poweroff of deep sleep)
def bye(): sys.exit(0)

## `HALT ( -- )` stop system until external event happens (sleep mode)
def halt():
    while True: time.sleep(0.1)

## `EXEC ( item -- )` execute item on a stack top
def exec(): pop()()
```

## subtitles
### ru

Мы забыли пару слов, которые решат вим-проблему выхода из системы, и её останова

слово `ноп` ничего не делает, и используется как заполнитель, когда нам нужна
дамми-команда (что-то что можно выполнить не меняя ничего в системе, или
скомпилировать пустой цикл виртуальной машины)

`бай` завершает работу виртуальной машины, закрывает процесс, и выполняет выход
в операционную систему, если форт-машина сделана в виде обычного приложения. Для
устройств на микроконтроллере выполняется отключение питания, или переход в
режим глубокого сна, из которого можно выйти только рестартом или внешним
awaik-событием.

слово `хальт` делает более мягкий останов: запускает цикл ожидания асинхронных
событий и приостанавливает текущий тред, или переключается в спящий режим с
сохранением состояния памяти.
