***37: Vocabulary***

```py
W = {} ## vocabulary Words

## fill vocabulary (most simple version w/o attributes & @ref M memory)
W['NOP'] = nop; W['BYE'] = bye; W

# {'NOP': <function nop at 0x4a840>, 'BYE': <function bye at 0x4a8e0>}

## `WORD ( -- name )` get word name from source code stream (lexer)
def word(): push('NOP') # lexer()

## `FIND ( name:str -- item|none )` find item in vocabulary by it's name
def find(): push(W.get(pop(), None))

## `EXEC ( item -- )` execute (found) item on a stack top
def exec(): pop()()
```

### ru

Словарь форт-системы это критически важный компонент, который делает возможным в
принципе существование Форта как языка и концепции. Словарь это аналог таблицы
символов в любом компиляторе или ассемблере. Он хранит перечень имён известных
компонентов программы (в нашем случае форт-слов и переменных), адреса их
размещения в памяти, и дополнительные атрибуты.

Самый простой форт-интерпретатор состоит из бесконечного цикла ворд-файнд-экзэк
- `ворд` читает входной поток и возвращает имя слова для поиска
- `файнд` ищет слово в словаре
- `экзэк` выполняет найденное слово, беря указатель на него со стека
