tokens = ['INT', 'NUM', 'WORD']

t_ignore_comment = r'\\.*'

## subtitles
### ru

Так как в дальнейшем мы хотим усложнить язык, оставив для его исполнения только
рантайм в виде виртуальной форт-машины, есть смысл сразу заменить классическое
слово `ворд` оперирующее строками, на полноценный лексер. Лексер не только
сможет вычленять группы символов как имена слов для поиска, но будет возвращать
типизированные токены. Лексер опреляется как набор правил на регулярных
выражениях, и способен сразу определить является ли группы символов записью
целого числа, числа с плавающей точкой, строки, или имени слова.

Для создания лексера будем использовать питон-библиотеку PLY.

Для начала будем распознавать только два вида чисел и имена слов, как раз тот
набор, который есть в любом Форте. Для лексера нужно определить список `токенс`,
содержащий названия всех типов токенов.

Каждому типу токена соответствует правило, содержащее регулярное выражение, с
именем начинающимся с префикса Тэ-подсёркивание. Правило может создаваться в
двух вариантах -- как строковая переменная, и как функция. Определение правила в
виде функции даёт больше контроля, в частности, токен можно вернуть любым другим
типом, содержащим поле `валуэ`, или сразу преобразовать значение токена в число.

Правила, начинающиеся с Тэ-ингорэ, задают правила для фрагментов кода, которые
будут отброшены. В частности, нам не нужны пробелы, и ещё мы отбрасываем
строковые комментарии, начинающиеся с бэк-слэш.
