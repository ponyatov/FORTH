***39: Lexer***

```py
## count lines using EOL chars as delimiter
def t_newline(t):
    r'\n+'
    t.lexer.lineno += len(t.value)

## integer number rule: regexp + token value conversion from string
def t_INT(t):
    r'[+\-]?[0-9]+'
    t.value = int(t.value); return t

## group of any non-space chars
def t_WORD(t):
    r'[^ \t\r\n]+'
    return t
```

## subtitles
### ru

Правила в виде функций имеют параметр Тэ. Это текущий токен, который уже был
распознан библиотекой питон лекс йакк, а мы задаём в правиле его дополнительную
обработку.

- Если токен не возвращать из функции-правила, он тоже будет отброшен
- если токен просто вернуть как есть, правило аналогично правилу заданному
  строковой переменной
- Также мы может задать в правиле произвольную обработку токена, и потом вернуть
  его уже изменённым

Для диагностики ошибок нам нужен подсчёт строк, это мы делаем в правиле
тэ-ньюлайн. В токене есть ссылка на лексер, и мы можем создавать в нём
переменные, чтобы передавать состояние лексера между правилами, в процессе его
работы. В том числе, внутри лексера есть предопределённая переменная лайн-но,
которую мы можем увеличить на количество найденных подряд концов строк.

В приведённом примере мы считаем концы строк в формате юникс (линукс) с одним
лайн фид. Если вы делаете Форт под виндоуз или макос, там используются концы
строк из двух символов, carriage return и line feed. В предыдущем слайде мы как
раз добавили через слэш эр игорирование carriage return как пробела.

Далее мы определяем правило для распознавания целых чисел с необязательным
знаком-префиксом. В библиотеке пли есть тонкость в определении правил: если нам
важен порядок применения правил лексера, они должны задаваться функциями.
Соответственно, сначала мы должны проверить группу символов, не является ли она
записью числа, и только если это не так, считать эту группу произвольным именем
слова.

При срабатываннии правила регулярное выражение уже гарантирует нам, что мы
получили корректную запись целого числа, и нам нужно только преобразовать его
собственно в число, и вернуть в составе токена как поле `валуэ`.

Распознавание чисел с плавающей точкой мы пока пропускаем -- там достаточно
сложное регулярное выражение, которое вы можете найти, или изобрести
самостоятельно.

Последним правилом идёт распознавание любой группы непробельных символов как имя
слова. Это правило сработает только в том случае, если все предыдущие не
подошли. В этом правиле нет никаких преобразований, и мы могли бы написать его в
виде строковой переменной с таким же именем, но нам важно сохранить порядок
применения. Если вы будете дописывать новые правила лексера, типа распознавания
комплексных чисел, электронных или ай пи адресов и т.п. следите за тем чтобы
правило тэ ворд всегда оставалось последним.
