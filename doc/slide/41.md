```py
## `INPUT ( -- )` get next source code string or user input
## @details into @ref PAD in case of low-level FORTH system
def input_(): lexer.input(input(f'{lexer.lineno}> '))

## `TOKEN ( -- token|None )` call lexer to get next token
def token(): push(lexer.token())

## `REPL ( -- )` run CLI loop
def REPL():
    while True:
        dump() ; input_()
        while True:
            token()
            if top() is None: drop(); break
```

## subtitles
### ru

- РЕПЛ это Read-Eval-Print-Loop или цикл чтение-исполнение-вывод
- КЛИ это Command Line Interface или интерфейс командной строки
- также часто такой интерфейс с программой или системой называют консолью

Несмотря на массовое распространение графического интерфейса, консоль всё ещё
популярна в тех случаях, когда текстовый ввод команд или фрагментов кода
оказывается удобнее и эффективнее, чем елозить мышью по десяткам вложенных меню.

Запустив программу, вы получаете текстовое окно и приглашение к вводу команды.
Либо это может выглядеть как графическое окно, а ввод команд выполняется в
отдельном текстовом поле внизу.

Для встраиваемых системах и устройствах на микроконтроллере вы подключатесь
программой-терминалом через телнет или последовательный порт, и получаете
командный интерфейс в текстовом режиме. Аналогично, вы можете открыть консоль на
одной из страниц веб-интерфейса.
